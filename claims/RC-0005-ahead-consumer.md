# RC-0005 — Ahead creation refuses an existing surface at the decoded base

**Level:** SOURCE_INSPECTED. **Subject:** bbhost `566184a74f071166299bb656c4af479e5bbe2771`, Vulkan texture consumer. **Checked:** 2026-10-12. **Independent review:** [r1 source review](../docs/reviews/BRC-GX-LIFECYCLE-01-REVIEW-r1.md) and [same-reviewer affected recheck](../docs/reviews/BRC-GX-LIFECYCLE-01-REVIEW-r2.md) support this unchanged claim in [exact candidate r2](https://github.com/Parm-1/Bloodborne-Research-Commons/tree/9f67163b468ffdc71ada998acb2b0843c0160f68), accepted by the parent at source/documentation scope. R3 integrates review status only; fresh-reader validation remains pending.

After the registry worker's current-range check, the host adapter locks `g.mu`. `textures_create_ahead_locked` refuses ahead creation when `g_surfaces` already contains the decoded base. This is a downstream safeguard against an older queued job creating over an existing Surface; it is not an original-resource token comparison.

**Source/method:** traced job producer/dequeuer, adapter and consumer: [gx_resources.cpp:308–367](https://github.com/droogie/bbhost/blob/566184a74f071166299bb656c4af479e5bbe2771/src/engine/gx_resources.cpp#L308-L367), [gpu.cpp:6688–6691](https://github.com/droogie/bbhost/blob/566184a74f071166299bb656c4af479e5bbe2771/src/host/gpu.cpp#L6688-L6691), [textures.cpp:2913–2936](https://github.com/droogie/bbhost/blob/566184a74f071166299bb656c4af479e5bbe2771/src/host/textures.cpp#L2913-L2936). Ordinary bind resolution additionally compares selected shape/format fields and defers incompatible replacements: [2445–2553](https://github.com/droogie/bbhost/blob/566184a74f071166299bb656c4af479e5bbe2771/src/host/textures.cpp#L2445-L2553).

**Meaningful negative:** if B covers A's saved range and B's Surface already exists, the old job declines rather than overwriting it. If no Surface exists and saved descriptor/computed mapping checks pass, current range coverage alone does not distinguish A from B: `AheadJob` saves descriptor/range, no resource ID. These conditional branches were not executed and establish no game bug.

**Exclusions/unknowns:** allocation synchronization, original descriptor/content authority, async guest-source retention and game reachability. A successful ahead return is not prep or fence completion.
