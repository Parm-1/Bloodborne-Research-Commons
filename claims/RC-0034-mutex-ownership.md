# RC-0034 — A recursive unlock success need not release the mutex

Under valid storage, race-free normal-path and compatible host-contract premises, this implementation translates guest type2 to native RECURSIVE. Successful lock plus successful recursive trylock increments depth twice; the first successful unlock can leave ownership held at depth1. Therefore unlock0 alone is not a complete release endpoint. The wrapper has no owner/depth field; its global diagnostic counts cannot supply the missing per-object premise.
