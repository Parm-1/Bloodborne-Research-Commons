# RC-0006 — Normal texture retirement defers object destruction to a slot fence

**Level:** SOURCE_INSPECTED. **Subject:** bbhost `566184a74f071166299bb656c4af479e5bbe2771`, Vulkan texture retirement. **Checked:** 2026-10-12. **Independent review:** [r1 source review](../docs/reviews/BRC-GX-LIFECYCLE-01-REVIEW-r1.md), [r2 F1/F2 recheck](../docs/reviews/BRC-GX-LIFECYCLE-01-REVIEW-r2.md) and [r3 refresh-predicate recheck](../docs/reviews/BRC-GX-LIFECYCLE-01-REVIEW-r3.md). This claim's body is unchanged in [accepted r3](https://github.com/Parm-1/Bloodborne-Research-Commons/tree/54695ff00e3452d94df939b2c86021088e3897d4), at source/documentation scope. R4 integrates status only; fresh-reader validation remains pending.

For a due retirement entry, the consumer keeps a Surface if a current GX range covers its full source span; otherwise it erases the Surface and adds its image/views to the current slot's deferred lists. Normal object destruction occurs only after that slot's successful fence wait. Registry removal or reaching the software CP retirement threshold therefore does not itself establish object destruction.

**Source/method:** [textures.cpp:3295–3351](https://github.com/droogie/bbhost/blob/566184a74f071166299bb656c4af479e5bbe2771/src/host/textures.cpp#L3295-L3351); deferred insertion [gpu.cpp:4655–4663](https://github.com/droogie/bbhost/blob/566184a74f071166299bb656c4af479e5bbe2771/src/host/gpu.cpp#L4655-L4663), [4904–4917](https://github.com/droogie/bbhost/blob/566184a74f071166299bb656c4af479e5bbe2771/src/host/gpu.cpp#L4904-L4917); slot completion [4165–4247](https://github.com/droogie/bbhost/blob/566184a74f071166299bb656c4af479e5bbe2771/src/host/gpu.cpp#L4165-L4247). CP totals count job insertion and post-walk retirement: [gnm_exec.cpp:2281–2295](https://github.com/droogie/bbhost/blob/566184a74f071166299bb656c4af479e5bbe2771/src/hle/gnm_exec.cpp#L2281-L2295), [2419–2432](https://github.com/droogie/bbhost/blob/566184a74f071166299bb656c4af479e5bbe2771/src/hle/gnm_exec.cpp#L2419-L2432).

Failed/timeout fence wait skips normal destruction/completion. These are source deductions, not GPU trials.
