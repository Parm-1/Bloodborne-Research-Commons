## How to continue

1. Read the selected dossier and its linked claim. Follow its primary-source links for the producer and the decisive consumer or dependency; keep source inspection separate from a test or game observation.
2. Read the linked frontier for the still-open premise. Reuse an existing mechanism only within its recorded inputs, consumer, configuration and version.
3. Use the [copyable continuation prompt](docs/CONTINUATION.md#copyable-continuation-prompt) in the actual target project. Read that project's records and authorization before proposing an action. Ask one precise question if an essential target, input, owner or permitted action is missing.
4. For each task answer, name the applicable source commit or commits for every repository used, the platform and configuration, and any authorization, eligibility and identity-phase premise that a prospective execution needs. The [continuation prompt](docs/CONTINUATION.md#copyable-continuation-prompt) already asks for these fields. A field that the project does not supply is UNKNOWN; do not infer it from a nearby pin or branch.
