## Findings for independent challenge

- Guest IDs select host wall/coarse wall, monotonic, calling-thread CPU or host-process CPU domains. Aliases do not implement separate network/raw/suspend clocks. ID13 clears nsec after coarse read, but clock_getres copies the unmodified host resolution. Matching units do not align domain/epoch/caller identity or establish accuracy.
- Process counters use a constructor monotonic sample rather than a CPU-time/guest-boot epoch. Ordinary unsigned borrow recovery preserves a valid elapsed nanosecond interval below2^64, but process_us divides the signed nanosecond difference before adding seconds. Constructor(10,900000001), current(11,100000000) gives199999999ns and200000us, versus floor(counter/1000)=199999us. Native signed-subtraction/representation and successful-sample premises are explicit; static initialization does not establish a successful constructor clock.
- Bare kernel RDTSC is a distinct producer from the GPU shim's LFENCE/RDTSC/LFENCE helper. TSC frequency is an unchecked, single-relative-sleep, measured-denominator quotient cached in plain uint64; interruption, zero fallback, pre-division unsigned product wrap and data-racy cache use limit interpretation. Fixed counter scale1GHz is not TSC frequency or one-nanosecond resolution. No current CPU/core/hypervisor/compiler artifact or ordering/rate qualification exists here.
- Sleep helper retries EINTR using local remaining time, exits on success or another error, measures a→b and returns a host result. All selected wrappers discard it. Valid POSIX/SCE nanosleep0/rem0 can accompany host success or an independently supplied non-EINTR host error; the conditional error branch does not prove that an unmodified conforming host returns that error for a valid short request. Validation22 is an earlier phase, leaves rem unchanged and never enters the helper. uint64 scaling permits positive huge requests to wrap before native conversion.
- Diagnostic sleep count is one per helper reaching instrumentation, including errors and all retries, not an attempt or per-caller completion receipt. Measured a→b excludes later instrumentation and differs from requested/exclusively-blocked time. Separate atomic exchanges can split count/duration across reports; plain wait-note initialization/metadata and signed diagnostic arithmetic require their own no-race/nonoverflow premises.
- Capability/function intake and exact NID lookup matter. runtime_time's exact #I#J timeval route precedes runtime_kernel's name fallback #p#J; first route exits21 on host error, fallback ignores status. Native timezone fields may not be initialized on a libc that ignores that argument. The kernel table has no selected mapping for counter/frequency, TSC frequency, getres or SCE nanosleep despite exports. Final GPU fallback is distinct; table absence is not a blanket global unreachability claim. Direct shim consumers exist.
