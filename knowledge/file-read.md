## Configure → translation/open

New mounts reject count16, guest length≥64 or host length≥512. Updating an existing exact guest happens before length checks and silently truncates its host to511 bytes. user_root and intermediate configure path formatting are also unchecked; a setup premise must identify the actual stored mappings.

Translation adds `/app0/` to a relative path, copies into a1024-byte buffer **without checking truncation**, then rejects exact slash-delimited `..` components in that stored prefix. It selects the longest case-sensitive mount prefix with an end/slash boundary under the mutex; `/app0x` does not match `/app0`. It concatenates stored host and suffix, with output truncation detected as ENAMETOOLONG. Duplicate slashes, `.`, symlinks and host canonical containment are not resolved/validated here. An overlong original guest can lose its suffix, including a later `..`, before inspection. Translation0 certifies only this textual operation. Mounting/unmounting changes future translations; it does not close existing Files.

[src/runtime_file.c:136–174](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/src/runtime_file.c#L136-L174) case correction is a conditional retry after ENOENT, only for non-save opens without guest CREATE0x200 and only for absolute host paths. It walks components, tries exact access first, otherwise takes the first readdir case-insensitive match; returns correction only if final text differs and total length is unchanged. It is not a canonical asset selection rule: relative roots cannot use it, ambiguous case matches follow listing order, and original PS4 case assertions remain reports.

[src/runtime_file.c:225–231](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/src/runtime_file.c#L225-L231) and [src/runtime_file.c:308–362](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/src/runtime_file.c#L308-L362) reject guest-relative or `/app0`/`/hostapp` write/append/create/truncate/exclusive requests before translation using mask `(3|0x8|0x200|0x400|0x800)`. ## Descriptor → call → close phases

[src/runtime_file.c:217–219](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/src/runtime_file.c#L217-L219) and [src/runtime_file.c:364–437](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/src/runtime_file.c#L364-L437) implement these phases:

| Phase | Source operation / identity | Supported fact and required limit |
|---|---|---|
| Lookup | fd0..2 passes straight to the same host integer; otherwise get requires used slot3..1023 | No lock/refcount/generation is acquired by host_fd; a previously opened integer alone is insufficient |
| Before host read | note_write(buffer, requested size), then touch_for_write | The requested span is notified before transfer; touch reads **and writes** one volatile byte per intersected4KiB page, including the first byte; these are real accesses even at EOF |
| Host attempt | up to8 read/pread calls; break on n≥0 or non-EFAULT | Only EFAULT retries; EINTR/other errors return without retry; a positive short call is not filled by another call |
| Failed EFAULT retry | touch requested span after each EFAULT, including attempt8 | No ninth syscall. The comment says nothing read, but no host failure-side-effect or unchanged-offset proof is provided; touch/hook normal return is a premise. errno is read after touching, not snapshotted at the failed syscall |
| Positive final attempt | n>0: note_write(buffer,n), then reads++, bytes_read+=n; return n | Post-note occurs after final transfer, before return, for the prefix n. It does not report earlier error-attempt effects or the whole request; counters aggregate successful calls, including zero, without asset/incarnation identity |
| Zero final attempt | no positive post-note; reads++, bytes_read unchanged; return0 | Pre-note/touch already occurred for a nonzero request. EOF needs host-file/offset/nonzero-size premises; no tail initialization occurs |
| Error final attempt | return-host errno; no successful counters/post-note | Bad lookup returns-EBADF before note/touch; later host failure can follow both accesses. No atomic rollback or unchanged-buffer certificate |
| Guest close | copy File, clear slot under mutex, unlock; free listing; ordinary close or save commit; free strings | Slot retired before host close; ordinary host close error is ignored and result0. fd0..2 close returns0 without host close. No wait/cancel of in-flight reads, retained incarnation or join endpoint |

Destination lifetime must cover **all** pre-note/touch, host attempts/retry touches and post-note through return, with valid read/write access and ordered writers. Empty spans skip touch and note's body, but still reach host read. The source accepts uint64 size and int64 offset without local range/null/overflow checks; uintptr addition in touch/note and conversions to host size_t/off_t require explicit nonwrapping/representable premises. A null destination is not safely rejected before touch for nonzero size. Return does not establish allocation ownership for a downstream CPU/GPU reader.
