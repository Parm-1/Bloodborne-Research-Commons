## Producer and phase boundary

[Decode entry and length](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/shader_recompiler/frontend/decode.cpp#L111-L174) recognize MUBUF as eight bytes; [64-bit dispatch](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/shader_recompiler/frontend/decode.cpp#L385-L410) reads that word. The [MUBUF producer](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/shader_recompiler/frontend/decode.cpp#L894-L957) extracts opcode bits 24:18, vaddr 39:32, vdata 47:40, srsrc 52:48 and soffset 63:56. Opcode 12 selects this operation and sets decoded count=1 and size=4; count/size are decoder metadata, not independent raw instruction fields. srsrc is a five-bit selector of a four-SGPR group, not a byte address. soffset is an eight-bit operand encoding, not an eight-bit byte offset: its resolved U32 value comes from [operand classification](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/shader_recompiler/frontend/decode.cpp#L331-L345) and [GetSrc](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/shader_recompiler/frontend/translate/translate.cpp#L338-L467). SGPR inputs and inline constants are distinct; e.g. code 193 resolves to U32 `0xffffffff`, not 193 bytes.

The [control layout](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/shader_recompiler/frontend/instruction.h#L175-L188) declares offset as 12 bits; offen, idxen, glc, addr64 and lds at bits 12–16; slc and tfe at 54–55. Decoder interpretation uses C++ bitfields and a reinterpretation of the host-read word. The contract assumes this host/compiler layout and byte order represent the intended fields; no portable serialized decoder or ABI qualification was executed. The [slice reader](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/shader_recompiler/frontend/decode.h#L27-L56) reads without checking available length at each access. Complete valid instruction input is a premise, not demonstrated malformed-input robustness.

[Translation dispatch/body](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/shader_recompiler/frontend/translate/vector_memory.cpp#L207-L273) uses the defaults scalar_width=32, is_signed=false, and num_dwords=1, typed=false. It produces `(index, voffset, soffset)` as three U32 values and a handle made from SGPRs `4*srsrc` through `4*srsrc+3`. If idxen is set, index is vaddr and the possible offset is vaddr+1; otherwise index is zero and the possible offset is vaddr. offen independently enables that offset. The destination is vdata. [IR emission](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/shader_recompiler/ir/ir_emitter.cpp#L439-L453) selects LoadBufferU32, and [register storage](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/shader_recompiler/ir/ir_emitter.cpp#L134-L154) preserves U32 bits. There is no numerical float conversion, sign extension, descriptor format conversion or destination swizzle in this selected raw load. The instruction-format table's Float32 destination label does not supersede the explicit U32 operation.

**Stage comes before the load conclusion.** [Pass order](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/shader_recompiler/recompiler.cpp#L90-L152) runs ring elimination before resource discovery/patching. For hardware Geometry stage, [both glc and slc](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/shader_recompiler/ir/passes/ring_access_elimination.cpp#L91-L126) select an attribute read followed by a float-to-U32 bitcast: vertex index is the selected immediate index/offset argument >>2; soffset/256 chooses the attribute and component. This is not a storage-buffer access. Its `.U32()` operands need immediate-value premises. For the ordinary load below, require that rewrite not to apply and that the load survive optimization/control flow. Control-flow, execution-mask fidelity and every intervening optimization are not independently qualified here.

addr64, lds and tfe do not enter this BUFFER_LOAD body's address/result decisions; tfe produces no second status VGPR here. Treat zero for these bits as an applicability premise; do not claim support or correct rejection when they are nonzero. glc/slc are carried in IR and affect the geometry rewrite, but the selected ordinary load emitter does not implement an instruction-level cache/coherency policy from them. Descriptor mtype and shared alias usage separately influence buffer decorations; neither flag proves synchronization.

## Descriptor identity and address arithmetic

[Discovery](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/shader_recompiler/ir/passes/resource_discover_pass.cpp#L244-L299) gathers the four descriptor dwords, looks through ReadFirstLane, and recognizes selected program-base and stride-OR patterns. [Patching](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/shader_recompiler/ir/passes/resource_patching_pass.cpp#L165-L216) records immediate/flattened descriptor sources, deduplicates resources and replaces the handle with the resource-list index; a later pass replaces the address composite. The descriptor comes from flattened user data at translation/specialization time, not a four-register descriptor read in the final load. [GetSharp](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/shader_recompiler/resource.h#L24-L118) applies recognized post-operations and substitutes a null descriptor (base=1, size=0) on unknown source location or nonzero descriptor type. Asserted source shapes, invalid/unflattened locations and null substitution are failure/limitation paths, not broad arbitrary-descriptor support. [RefreshFlatBuf](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/shader_recompiler/info.h#L242-L249) copies current user data and invokes its optional walker. The walker body was not audited; [the flatten pass's non-x86-64 branch](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/shader_recompiler/ir/passes/flatten_extended_userdata_pass.cpp#L861-L880) is explicitly unimplemented.

The [128-bit descriptor](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/video_core/amdgpu/resource.h#L14-L105) has base_address 40 bits, stride S 14 bits, num_records 32 bits, swizzle_enable one bit, element_size and index_stride two bits each, and add_tid_enable one bit. Its source GetSize is num_records for S=0, otherwise U32 S*num_records. Size and base are binding inputs, not additions inside the IR-relative address. The selected raw load's address shift is always 2, independent of descriptor format.

[CalculateBufferAddress](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/shader_recompiler/ir/passes/resource_patching_pass.cpp#L546-L636) has two different arithmetic branches. All additions/multiplications below are U32, wrapping modulo 2^32; unsigned division/remainder and logical shifts are used. [Integer emission](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/shader_recompiler/backend/spirv/emit_spirv_integer.cpp#L86-L136) preserves these integer operations, not signed address arithmetic.

Let I be the enabled index value, V the enabled vector offset, O the resolved scalar value, D the 12-bit instruction offset, and J the emitted dword index before binding adjustment.

| Branch | Exact selected arithmetic |
|---|---|
| Aligned shortcut: idxen=1, offen=0, O immediate in IR, swizzle=0, add_tid=0, S divisible by 4, and U32(O+D) divisible by 4 | J = U32(I*(S>>2) + (U32(O+D)>>2)). Being an SGPR encoding does not prevent O becoming immediate after propagation. |
| General nonswizzled | K = U32(I + L), with I=0 when idxen=0; L=LaneId if add_tid=1, otherwise 0. T=U32(D+O+V), V=0 when offen=0. B=U32(K*S+T); J=B>>2. |
| General swizzled | A=8<<index_stride; E=2<<element_size. B=U32((U32((K/A)*S + (T/E)*E))*A + (K%A)*E + (T%E)); J=B>>2. |

add_tid asserts software Compute stage and adds emitted [SubgroupLocalInvocationId](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/shader_recompiler/backend/spirv/emit_spirv_warp.cpp#L17-L19). This source does not mask it to six bits. Device subgroup size/mapping is a profile premise, not proven PS4 lane identity. The low two byte-address bits are discarded in the general branch. There is no unaligned four-byte reconstruction in this path. The shortcut does not generally equal `(wrapped byte address)>>2` when byte multiplication overflows; the worked counterexample below is part of the contract.

## Generated load and actual binding consumer

[SPIR-V dispatch/assembly](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/shader_recompiler/backend/spirv/emit_spirv.cpp#L122-L131) routes LoadBufferU32 to [the N=1 emitter](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/shader_recompiler/backend/spirv/emit_spirv_context_get_set.cpp#L432-L456). U32 has a 32-bit unsigned SPIR-V type. Buffer definitions use storage-buffer blocks of runtime arrays, dword stride 4, descriptor set 0 and the current unified binding; aliases share a binding. For the selected N=1 path:

- A **bound buffer** adds the optional dword binding adjustment and emits OpAccessChain + OpLoad U32. No descriptor-size comparison occurs in this emitter. [Buffer properties](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/shader_recompiler/backend/spirv/spirv_emit_context.cpp#L235-L275) extract an eight-bit push-data adjustment and shift it by 2 when `needs_buffer_offsets`. [Runtime binding](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/video_core/renderer_vulkan/vk_rasterizer.cpp#L3100-L3185) obtains a buffer for the guest base, clamps size, aligns its offset down, publishes the adjustment and a range capped by the backing buffer end. Zero base/size binds a null descriptor. [PushData](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/shader_recompiler/resource.h#L220-L247) asserts adjustment<256; a non-dword adjustment only logs a warning at binding. Require a matching dword-aligned adjustment and backing span, not just matching descriptor bytes.
- A **paged buffer** requires profile.paged_buffers, nonzero guest base and source GetSize >=64 MiB. [Definition selection](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/shader_recompiler/backend/spirv/spirv_emit_context.cpp#L867-L922) binds a record instead of raw data. [Record production](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/video_core/buffer_cache/buffer_cache_layer.cpp#L1137-L1206) supplies guest base, capped U32 size, trash address and table metadata; runtime publishes adjustment zero and record range 32 bytes. PagedLoad converts J back to U32 byte offset `J<<2`. [PagedPointer](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/shader_recompiler/backend/spirv/spirv_emit_context.cpp#L1338-L1379) guards `size>=4 && byte_offset<=size-4`, substitutes table index 0 outside range, then requires a nonzero entry; target is entry+in-page offset if guarded, otherwise trash. It emits an aligned physical-pointer load **even when guard is false**, then selects zero. A readable aligned trash allocation and safe table index 0 are premises; this is not a branch avoiding all reads. [Entry producer](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/video_core/buffer_cache/buffer_cache_layer.cpp#L978-L1054) populates current-view entries from valid guest spans and selected mirrors. Complete table range, coherence, GPU publication order, mapping lifetime and physical-page cross-boundary safety were not qualified here.

[Device/profile construction](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/video_core/renderer_vulkan/vk_pipeline_cache.cpp#L291-L362) selects SPIR-V 1.6, actual subgroup size, sparse page shift, alignment-dependent offsets and layer-dependent paging. The sparse page shift is not a free runtime input. [Buffer-cache initialization](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/video_core/buffer_cache/buffer_cache.cpp#L590-L612) aligns the maximum of device sparse-buffer alignment and [MIN_BLOCK_SIZE=16 KiB](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/video_core/buffer_cache/buffer_cache.h#L68-L72), asserts that the resulting block size is a power of two, then computes block_shift=bit_width(block_size)-1. Thus a successful source producer has shift>=14. [GetSparsePageShift](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/video_core/buffer_cache/buffer_cache.h#L104-L107) returns that value; [Rasterizer construction](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/video_core/renderer_vulkan/vk_rasterizer.cpp#L57-L63) passes it to the [PipelineCache profile](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/video_core/renderer_vulkan/vk_pipeline_cache.cpp#L290-L302). LayerWriteEntries uses the same block_shift for span and entry production. A freely supplied shift=12 cannot be used as a positive for this traced runtime producer. [LayerPagedActive](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/video_core/buffer_cache/buffer_cache_layer.cpp#L1193-L1206) additionally depends on the active layer and BB_LAYER_PAGED setting. The device source requires/enables [robustBufferAccess2 and nullDescriptor](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/video_core/renderer_vulkan/vk_instance.cpp#L280-L292). This is a requested-feature observation, not a tested out-of-bounds result or proof that descriptor robustness protects physical-pointer loads. Paged emission selects PhysicalStorageBuffer64 and its capability/extension; usable device addresses and table/trash resources remain premises.

[CompileModule](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/video_core/renderer_vulkan/vk_pipeline_cache.cpp#L1034-L1066) translates and emits, but may compile an external SPIR-V patch instead. [CompileSPV](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/video_core/renderer_vulkan/vk_shader_util.cpp#L9-L18) calls createShaderModule and asserts success; that is not execution, shader correctness or original-hardware fidelity. Successful compilation cannot identify the active emitted code without the patch-selection premise. [Specialization](https://github.com/deadinside28/bloodborne_pc/blob/3c57da4198ad62039f63f33bfd205b9916518acf/gpu/shadps4/shader_recompiler/specialization.h#L24-L45) includes stride, paging, swizzle and conditional swizzle/format fields; it has no add_tid or mtype field. This dossier assumes the selected descriptor/profile at fresh translation and matching bind. It does not establish safety of changing those fields during cache reuse. Cache applicability is a separate question, not a new claim here.

Conditional guarantee: if the selected instruction survives as this raw load, translation/binding inputs match, generated code is used, all accesses/resources are valid and the SPIR-V operations execute as specified, the bound route returns the selected U32 array element; the paged route returns the physical loaded U32 when guarded, otherwise zero after the trash load. It supplies no original-game ordering, ownership lease, memory-version snapshot, performance or hardware equivalence guarantee. Missing-opcode handling marks translation_failed; register limits, source shapes, compute-only add_tid and unsupported flatten architecture use assertions/unreachable paths. Nonzero omitted control bits are not checked into a safe fallback by this body.

## Original worked examples and discriminators

All values here are **supplied hypothetical premises**. Calculations are MODEL/source reasoning, not decoded outputs, serialized fixtures, emitted binaries or executed shaders. Use a fresh ordinary software/hardware Compute translation, supported host layout, addr64=lds=tfe=0, no patch, matching descriptor/binding and a surviving instruction, except where a row explicitly changes the stage. Assume dword alignment and no wrap in positive rows. For decoding, srsrc=2 selects s[8:11], vaddr=5 and vdata=9. SGPR s0 is supplied with the indicated O; an IR immediate is stated separately when needed.

| Positive phase/control | Source-faithful result |
|---|---|
| Decode/front end: raw op=12, idxen=offen=1, offset D=12; v5=3, v6=20, s0=4 | Metadata count=1,size=4; handle s[8:11]; address tuple (3,20,4); destination v9; no second destination. |
| General nonswizzled: preceding tuple, S=16 | T=12+4+20=36; B=3*16+36=84; J=21. With host adjustment 12 and offsets enabled, final bound-array index=24. Guest base is supplied by binding, not added to J. |
| Aligned shortcut: idxen=1,offen=0; I=3,S=16,D=12,O=4 immediate | J=3*(16>>2)+((4+12)>>2)=16. General nonoverflow byte arithmetic gives 64>>2=16 too. |
| Offset only: idxen=0,offen=1; v5=20,v6=999,D=12,O=4,S=16 | Tuple (0,20,4); B=36,J=9. v6 is unused. With both flags zero, B=16,J=4 regardless of v5. |
| Swizzled: idxen=offen=1; K=10,T=12,S=16,index_stride=0,element_size=1 | A=8,E=4; B=((1*16+3*4)*8)+(2*4)+0=232; J=58. |
| Compute add_tid: I=3,L=5,T=36,S=16,swizzle=0 | K=8,B=164,J=41. L is a supplied subgroup-local value, not proof of original lane identity. |
| Paged positive with the producer/binding premises below: descriptor base=0x5000,S=16,num_records=0x400000; J=21; device sparse alignment=16 KiB | GetSize=64 MiB; block_size=16 KiB,shift=14; byte_offset=84; address=0x5054; page=1,in_page=0x1054; guard true; target=0x801054. A supplied word 0x3f800000 stays U32 0x3f800000 in v9; it is not numerical integer 1. |
| Geometry alternative: glc=slc=1, idxen=1, immediate index=8, immediate O=256 | Ring rewrite chooses vertex 2, bucket 1, Position0 component 1 and bitcasts the attribute's float bits. No descriptor load address is produced by that instruction afterward. |

The paged row additionally supplies these **hypothetical producer-compatible premises**, not execution facts: device reqs.alignment=0x4000 yields AlignUp(max(0x4000,0x4000),0x4000)=0x4000 and shift 14; layer paging is active in both translation and binding; the exact same valid, nonswizzled, add_tid=0 descriptor (base=0x5000, stride=16, num_records=0x400000, type=0) is used at both phases. The read page table is allocated through index 4097 inclusive, including fallback index 0, covering the descriptor's block interval [1,4098). LayerWriteEntries resolves the complete guest block [0x4000,0x8000) to a readable physical span [0x800000,0x804000), with no selected mirror overriding it, and publishes read entry[1]=0x800000 before the load. The paged record carries that descriptor base/size, a readable aligned trash allocation and valid table metadata; its same unified binding is a readable 32-byte record, with published adjustment zero. The four-byte target span [0x801054,0x801058) is within the supplied physical block and contains the supplied word. Matching code/profile, stable resources and required publication/order through this one load remain premises. These premises allow the selected entry to exist under the actual source producer; they do not establish a real mapping or device result.

| Contrary/raw-field case | What it discriminates |
|---|---|
| Same general tuple but idxen=0,offen=1, unchanged v5=3,v6=20 | v5 becomes the byte offset, not index: B=12+4+3=19,J=4. Blindly retaining the tuple or J=21 is wrong. |
| Same swizzle inputs with swizzle_enable=0 | B=10*16+12=172,J=43, not 58; descriptor format or dst-select changes alone do not make the raw load formatted. |
| General nonswizzled byte result B=19 vs B=16 | Both yield J=4; the path does not preserve a byte-granular unaligned start. An expected four-byte splice beginning at byte 19 is unsupported. |
| Aligned shortcut I=0x10000000,S=16,D=O=0,idxen=1,offen=0,swizzle=add_tid=0,O immediate | Shortcut J=0x40000000; wrapped general-byte formula U32(I*16)>>2=0. This falsifies unconditional equivalence of the two arithmetic formulas. It is not an executed defect or an ISA correctness verdict. If O is non-immediate, the general branch is selected instead. |
| Paged size=64 MiB, byte_offset=size-4 vs size | Former is within guard; latter returns selected zero via trash. Also size<4 or a zero table entry fails guard. “No load occurs on failure” is false: trash is loaded first. |
| Paged J=0x40000000 | U32(J<<2)=0. The paged guard sees offset zero, not a 4-GiB offset; it does not restore high bits lost by this conversion. This combines with the shortcut overflow case, conditional on paging and a valid descriptor. |
| tfe=1, or addr64=1, or lds=1 in otherwise identical raw fields | The selected body has no corresponding result/address branch; opcode recognition is insufficient to claim support, status delivery or rejection. |
| Change compute to noncompute while add_tid=1; or geometry flags from both 1 to one 0 | First reaches the compute-only assertion. Second fails ring rewrite selection and leaves the ordinary path eligible. “All stages use the same buffer access” is falsified. |
| soffset encoding 193 vs SGPR encoding 0 with supplied s0=193 | Former resolves to 0xffffffff; latter to 193. Treating both encodings as byte 193 is wrong. |

These are document calculations and source discriminators only. No flag named “correct” or expectation generated by a checker is evidence that the producer ran. Positive rows cover decode/front end, shortcut/general/swizzle/add_tid patching, bound/paged emission and geometry alternative; negatives change actual input fields or arithmetic premises.
