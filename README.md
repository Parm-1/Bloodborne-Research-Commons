## Boundaries

Claims describe only the cited public source and stated scope. A guest address is an address in the emulated game's memory; the host is the port process. A GPU (graphics processing unit) completion fence signals that submitted host graphics work finished. None of these facts alone proves original game ownership. Source comments and project reports are not independent game evidence. No game binaries, proprietary assets, private research, credentials or unapproved code imports belong here. This is a research index, not a completed reverse-engineering corpus or shipping PC port. The Commons is an independent research index and is not affiliated with, endorsed by or maintained by the upstream projects it cites.
